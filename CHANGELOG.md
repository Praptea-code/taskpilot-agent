# Changelog

## v0.1.0

- FastAPI service with async SQLAlchemy storage and Alembic migrations.
- JSON-only LLM layer with Ollama, OpenAI compatible, and fake providers.
- Goal extraction, task decomposition, greedy scheduling, and check-in renegotiation.
- Local calendar, email, CRM, sales follow-up, and Google Calendar stub executors.
- Escalation policies, notifications, and bounded renegotiation turns.
- Inbound text and voice endpoints with optional faster-whisper and Piper support.
- Minimal React client with goal input, schedule list, chat, microphone button, and notifications.
- User API keys, rate limiting, encrypted per-user credentials, JSON logs, global error handling, and monitor claim idempotency.
- CI workflow, pre-commit hook, Docker image, and compose stack with Postgres, Mailpit, and Ollama.

## 2026-11-26 verification

- Fresh clone install, migrations, both offline demos, pytest, Ruff, web build, and compose config validation passed.
